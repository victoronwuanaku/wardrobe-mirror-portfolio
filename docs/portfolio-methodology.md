# Portfolio methodology overview

Wardrobe Mirror uses a reflection model that compares an initial self-assessment with responses about individual garments. The intent is not to assign a definitive score to a person; it is to give participants a structured prompt for noticing potential gaps between their values and day-to-day clothing decisions.

The feedback considers four value dimensions:

- social value
- emotional value
- functional value
- inflow/outflow value

Responses about acquisition, use, retention and disposal contribute to a visual value fingerprint and a descriptive behavioural archetype. The approach is transparent and theory-aligned, and it is not psychometrically validated.

This portfolio intentionally excludes detailed weights, scoring configuration, database design and raw question-to-score mappings. Those materials belong to the private research project.
